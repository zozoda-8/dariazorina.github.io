# dariazorina.github.io

Personal website — Дарья Зорина.

Статический сайт для GitHub Pages. Сборка не требуется.

- `index.html` — разметка и контент.
- `styles.css` — стили.
- `theme-init.js` — восстановление темы до первого отображения страницы.
- `main.js` — интерактивность и анимации.
- `assets/` — фотографии и лицензия иконок.
- `CNAME` — домен dariazorina.ru.

Загрузите содержимое этой папки в корень репозитория, сохранив структуру каталогов.
